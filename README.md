# ScreenGuide

An AI teaching companion that lives next to your cursor — it sees your screen, talks to you, and points at things to walk you through whatever you're doing.

This repo has two implementations:

- [`ScreenGuide-MacOS/`](ScreenGuide-MacOS) — native macOS menu bar app (Swift/SwiftUI)
- [`ScreenGuide-Windows/`](ScreenGuide-Windows) — Windows system tray app (Python/PyQt6)

Each has its own setup instructions in its README (`ScreenGuide-MacOS/README.md`, `ScreenGuide-Windows/README.md`).
